# 自動割草機（四輪）· 規格 v0

狀態：第 1 步「需求與規格」草案。數值多為估計起點，**不是計算結果**，待實測修正。

## 設計流程
1. 需求與規格（本檔）
2. 系統分解
3. CAD 骨架（CadQuery，單一來源 params）
4. 零件採購與 BOM
5. 列印與組裝（先印公差測試片）
6. 電控與測試：先不裝刀，RTK 沿邊界；安全測試通過才裝刀

## 使用者提供的條件
- 草地有坡，最陡約 12°。
- 草地旁有階梯；階梯在邊界內或外：**未確認**。
- 想用手機做視覺（遠近、辨識、避障、決策）。
- 想先用無人機勘查：確認割草範圍、評估障礙物、繪製邊界，再交給割草機執行。

## 規格（預設，待改）
| 項目 | 預設 | 備註 |
|---|---|---|
| 草地面積 | 約 100–300 m² | 待確認 |
| 最大坡度 | 設計 ≥ 15°，運轉限制 12° | 濕草地牽引力要實測 |
| 割幅 | 20–25 cm | 先用小刀盤降低風險 |
| 車體 | 約 50 × 40 × 25 cm | 重心壓低 |
| 速度 | 0.3–0.5 m/s | |
| 續航 | 約 1 小時 | |
| 驅動 | 後輪各一顆減速馬達加編碼器，前輪萬向 | 坡地可能需四驅，待評估 |
| 電源 | 24 V 鋰電加 BMS | |
| 定位 | RTK GNSS（公分級） | 一般 GPS 誤差 2–5 m，不可用 |

## 分層安全（硬性要求）
| 層 | 負責 | 位置 |
|---|---|---|
| 1 地理圍欄 | RTK 禁區；階梯邊緣外退 ≥ 50 cm | 大腦與 MCU 雙重檢查 |
| 2 懸崖感測 | 車頭向下 ToF 或超音波，地面突然變遠就停 | MCU 直接讀，不經手機 |
| 3 碰撞／抬起／傾斜 | 機械開關加 IMU，觸發即停刀停車 | MCU |
| 4 視覺 | 人、寵物、障礙物、草地語意、相對深度 | 手機 |

- 手機負責聰明，MCU 負責不死。手機當機或誤判，第 1–3 層仍會擋住。
- 刀盤獨立繼電器／MOSFET，預設斷電；實體急停鈕；大腦失聯 deadman 自動停車停刀。
- 單目深度是相對距離，要用 ToF 校正，不可單獨當懸崖判斷。

## 無人機勘查流程（構想）
1. 無人機以 RTK 或地面控制點拍攝草地。
2. 產生正射影像與高程模型，得到範圍、坡度圖、障礙物位置。
3. 在圖上標出邊界與禁區（階梯、花圃、樹），輸出為割草機的圍欄與路徑。
4. 割草機仍以自己的 RTK 加感測器安全層執行，**不因為有地圖就省略第 2、3 層**。
- 待查：台灣對無人機的註冊與飛行規定（在自家私有土地上飛行也要確認）。
