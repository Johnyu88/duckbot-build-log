# 印表機檔案與校正

每台印表機一份公差檔，放在 `hardware/cad/params.py` 的 `PRINTERS`。同一份設計換印表機，只要換檔，不用改零件。

## 我們的印表機
| 代號 | 狀態 | 備註 |
|---|---|---|
| main | 主印表機 | 公差未實測 |
| old | 不準的那台 | 先修機構再實測；型號與韌體待記錄 |

## 原則：先修機構，再用參數補償
補償只能處理**穩定、一致**的誤差（例如孔總是小 0.15 mm）。鬆動的皮帶、搖晃的框架、不穩定的擠出，造成的誤差不穩定，補償修不了。所以順序是：

1. **修機構：** 皮帶張力、皮帶輪固定螺絲、軸桿和框架是否垂直、噴嘴與熱端是否鬆動。
2. **校擠出量（E-steps／flow）：** 命令擠出 100 mm 耗材，量實際擠出長度，修正每毫米步數。
3. **校尺寸：** 印一個 20 mm 方塊，量 X、Y、Z，修正各軸每毫米步數。
4. **印公差測試片**（`hardware/cad/parts/tolerance_coupon.py`），量出孔偏差與外尺寸偏差。
5. **寫回 `params.PRINTERS`**，並把 `measured` 改成 `True`，在下表記一筆。

## 韌體
要不要換韌體或重寫，取決於印表機型號、主機板和目前韌體版本。**先記錄型號和主機板，再決定**，不要先動手。
